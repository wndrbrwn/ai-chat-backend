Title: OpenRouter FAQ

시작하기
OpenRouter를 사용해야 하는 이유는 무엇입니까?
OpenRouter는 주요 제공업체의 텍스트, 이미지 생성, 동영상 생성, 텍스트 음성 변환, 음성 텍스트 변환 모델을 하나의 API와 하나의 API 키로 제공하며, 통합 결제 및 사용량 분석을 지원합니다.

제공업체 가격을 그대로 적용하면서 가동 시간을 통합하므로, 동일한 제공업체 요금으로 통합 API와 안정성 향상을 위한 자동 대체 라우팅을 이용할 수 있습니다. 각 모달리티의 지원 내용은 멀티모달 개요 에서 확인하십시오.

OpenRouter를 시작하려면 어떻게 해야 합니까?
계정을 만들고 크레딧 페이지에서 크레딧을 추가하십시오. 크레딧은 LLM 추론에 사용됩니다.

채팅방을 사용하거나 API 키를 만들어 API 사용을 시작하십시오. 다음 빠른 시작 가이드를 참조하십시오

지원을 받으려면 어떻게 해야 합니까?
커뮤니티( Discord )에 참여하여 #help 포럼에 질문하십시오.

결제 및 계정 관련 질문은 이메일( support@openrouter.ai)로 보내주십시오.

OpenRouter 사용량에 대한 요금은 어떻게 청구됩니까?
요금은 모델별로 책정되며 프롬프트/완성, 이미지, 추론 토큰에 따라 다를 수 있습니다. 자세한 내용은 모델 페이지를 참조하십시오.

저희는 제공업체의 토큰 사용량을 기준으로 비용을 계산하고 크레딧에서 차감합니다. 사용 내역을 확인하십시오( 활동).

응답에 사용량 데이터를 받으려면 요청에 usage: {include: true} 을 포함하십시오. 제공업체 요금을 그대로 적용하며, 크레딧 구매 시 소액의 수수료를 부과합니다.

가격 및 수수료
OpenRouter 사용 수수료는 얼마입니까?
크레딧 구매 시 소액의 수수료를 부과합니다. 모델 추론 요금은 추가 마진 없이 제공업체의 요금 그대로 적용됩니다.

암호화폐 결제에는 추가 처리 수수료가 포함될 수 있습니다.

자체 제공업체 키(BYOK)를 사용하면 수수료가 발생합니까?
BYOK 사용에는 요청 수가 아닌 정가 기준 추론 비용으로 측정되는 요금제별 무료 허용량이 포함되며, 이후 사용량에는 5% 수수료가 해당 OpenRouter 비용을 기준으로 부과됩니다. 현재 허용량에 대한 자세한 내용은 요금 안내 페이지 에서 확인하십시오. 이 금액은 크레딧에서 차감됩니다.

모델 및 제공업체
OpenRouter는 어떤 LLM 모델을 지원합니까?
프런티어 모델을 포함한 다양한 모델을 이용할 수 있습니다. 다음에서 확인하십시오: 모델 탐색기 또는 모델 API.

새 모델은 얼마나 자주 추가됩니까?
모델을 정기적으로 추가하며, 연구소와 협력하는 경우도 많습니다. 누락된 모델이 있다면 다음 채널로 문의하십시오: Discord.

모델 변형이란 무엇입니까?
변형은 동작을 수정하는 접미사입니다. 정적 변형은 특정 모델에서 사용할 수 있으며 모델 API에 나열되어 있습니다:

:free – 속도 제한이 낮은 무료 모델
동적 변형은 모든 모델에서 사용할 수 있습니다:

:online – 프롬프트에 웹 결과 첨부
:nitro – 더 빠른 처리량을 위한 최적화
:floor – 최저 가격 우선

추론 제공업체인데, OpenRouter에 등록하려면 어떻게 해야 합니까?
참조: 제공업체 요구 사항. 문의는 이메일이 가장 좋습니다.

모델별 예상 지연 시간/응답 시간은 얼마입니까?
모델 페이지에는 제공업체별 지연 시간과 처리량이 표시됩니다. 더 빠른 제공업체로 라우팅하려면 :nitro 옵션을 사용하십시오.

제공업체를 사용할 수 없는 경우 모델 대체는 어떻게 작동합니까?
OpenRouter는 오류 발생 시 자동으로 다음 제공업체로 대체 라우팅합니다. 제공업체 라우팅 설정은 [ 문서]를 참조하십시오.

API 기술 사양
어떤 인증 방법이 지원됩니까?
웹/Chatroom에는 쿠키 기반 인증을, 완성 및 핵심 엔드포인트에는 API 키를, 관리 작업에는 Management API 키를 사용합니다.

속도 제한은 어떻게 계산됩니까?
무료 모델의 속도 제한은 구매한 크레딧에 따라 달라집니다. 자세한 내용은 다음을 참조하십시오: 속도 제한 문서.

어떤 API 엔드포인트를 사용할 수 있습니까?
다음 경로인 /api/v1 아래에서 OpenAI 호환 /chat/completions 및 /responses 를 텍스트 및 멀티모달 입력용으로, 레거시 텍스트 전용 /completions, 그리고 /images 기반 이미지 생성, /videos 기반 동영상 생성, /audio/speech 기반 텍스트 음성 변환, /audio/transcriptions 기반 음성 텍스트 변환, 그리고 /models를 구현합니다. 자세한 내용은 API 문서를 참조하십시오.

어떤 형식이 지원됩니까?
입력: 텍스트, 이미지, PDF, 오디오, 및 동영상. 이미지, PDF, 동영상은 URL 또는 base64 형식일 수 있으며, 오디오는 base64 형식입니다. 출력: 텍스트, 이미지, 동영상, 음성, 및 전사문. 다음 모델 페이지 에서 입력 및 출력 모달리티로 필터링하여 각 형식을 지원하는 모델을 찾으십시오.

스트리밍은 어떻게 작동합니까?
스트리밍은 실시간 토큰 전송에 SSE를 사용합니다. 설정값은 stream: true로 지정하십시오.

어떤 SDK 지원을 이용할 수 있습니까?
OpenRouter는 OpenAI를 그대로 대체할 수 있으며, 대부분의 OpenAI SDK가 작동합니다. 다음 문서를 참조하십시오: SDK 문서.

개인정보 보호 및 데이터 로깅
API 사용 중 어떤 데이터가 로그에 남습니까?
기본 요청 메타데이터(타임스탬프, 모델, 토큰 수)를 로그에 저장합니다. 프롬프트와 완성은 기본적으로 로그에 저장되지 않습니다.
소액 할인을 받으려면 프롬프트/완성 로깅을 개인정보 보호 설정에서 활성화할 수 있습니다.

Chatroom 사용 중 어떤 데이터가 로그에 남습니까?
대화는 기기에 로컬로 저장되며 기기 간에 동기화되지 않습니다. Chatroom 설정에서 대화를 내보내거나 가져올 수 있습니다.

어떤 제3자 공유가 이루어집니까?
요청은 프록시를 통해 모델 제공업체로 전달됩니다. 기본적으로 제공업체의 로깅이나 학습을 방지하는 것을 목표로 하며, 라우팅은 사용자의 개인정보 보호 설정을 따릅니다. 조건에 맞는 제공업체가 없으면 요청에 오류가 발생합니다.

크레딧 및 청구 시스템
어떤 구매 옵션이 있습니까?
OpenRouter는 USD 기준의 크레딧 시스템을 사용합니다. 수동으로 충전하거나 자동 충전을 활성화할 수 있습니다.

크레딧은 만료됩니까?
사용하지 않은 크레딧은 일 년 후 만료될 수 있습니다(근거: 약관).

크레딧이 계정에 반영되지 않았습니다
Stripe 구매는 최대 한 시간까지 기다려 주십시오. 청구 내역이나 영수증이 표시되지 않으면 카드가 거절되었을 수 있으므로 다른 결제 방법을 시도해 주십시오.

결제되었지만 크레딧이 누락된 경우 구매 세부 정보를 포함하여 다음 주소로 이메일을 보내 주십시오: support@openrouter.ai . 암호화폐 결제의 경우에도 지원팀에 이메일로 문의해 주십시오.

환불 정책은 어떻게 됩니까?
미사용 크레딧은 구매 후 24시간 이내에 크레딧 페이지의 환불 버튼을 통해 환불을 요청할 수 있습니다. 플랫폼 수수료는 환불되지 않습니다. 암호화폐 결제는 환불되지 않습니다.

크레딧 사용량은 어떻게 모니터링합니까?
잔액과 남은 크레딧은 활동 페이지 또는 크레딧 API 를 사용하여 확인하십시오.

어떤 무료 등급 옵션이 있습니까?
신규 사용자에게는 OpenRouter를 테스트할 수 있는 소량의 무료 사용량이 제공됩니다. 다양한 무료 모델을 사용할 수 있지만 속도 제한이 낮아 프로덕션에는 적합하지 않습니다. 크레딧을 구매하면 속도 제한이 높아집니다.

대량 사용 할인은 어떻게 적용됩니까?
현재 대량 사용 할인을 제공하지 않습니다. 특별한 사용 사례가 있으시면 문의해 주십시오.

어떤 결제 수단을 사용할 수 있습니까?
주요 신용카드, AliPay 및 USDC 암호화폐를 지원합니다. PayPal은 준비 중입니다. 다른 결제 방법은 다음 채널에서 문의하십시오: Discord.

OpenRouter는 어떻게 수익을 창출합니까?
크레딧 구매 시 소액의 수수료를 부과합니다. 제공업체 가격에는 절대로 추가 요금을 붙이지 않습니다.

계정 관리
계정을 삭제하려면 어떻게 해야 합니까?
계정을 삭제하려면 설정 → 계정 관리 → 보안 탭으로 이동하십시오.

참고: 계정을 삭제한 후 다시 만들면 사용하지 않은 크레딧이 소멸되며 복구할 수 없습니다.

팀 액세스는 어떻게 작동합니까?
자세한 내용은 조직 관리 문서를 참조하십시오.

어떤 분석 기능을 사용할 수 있습니까?
「 활동 대시보드 」는 실시간 사용량 지표를 제공합니다. 특정 보고서가 필요하면 문의하십시오.

지원팀에 어떻게 문의할 수 있습니까?
계정 및 결제 관련 문의는 이메일( support@openrouter.ai)로 보내주십시오.
